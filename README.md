# R Coursework

Academic coursework in R focused on data visualization, exploratory analysis, and communication of insights.

## Coursework

### Assignment 2
Analyzed U.S. election campaign finance data using R, ggplot2, and dplyr. Created visualizations comparing candidate status, fundraising, political parties, and election trends.

### Assignment 3
Extended the campaign finance analysis with additional visualizations and mapping. Explored how visualization choices can affect interpretation and created examples of misleading charts.

## Tools
R · ggplot2 · dplyr · maps
